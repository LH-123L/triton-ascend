# Random Number Generation

|api|Brief Description|
|--|--|
|[randint4x](./randint4x.md) |Given 1 seed scalar and 1 offset block, returns 4 random blocks of int32 type |
|[randint](./randint.md) |Given 1 seed scalar and 1 offset block, returns 1 random block of int32 type |
|[rand](./rand.md)   |Given 1 seed scalar and 1 offset block, returns 1 random block of float32 type in U(0,1) |
|[randn](./randn.md)   |Given 1 seed scalar and 1 offset block, returns 1 random block of float32 type in N(0,1) |
